BOUNDARY-LIMIT OPENNESS LEMMA (proved, conditional only on convergence hypotheses)
Let U be a complex parameter domain; let K_j be increasing compact subsets of an open Omega subset C^n, with union int(K_j)=Omega. Suppose F_j:U x C^n -> C^n are holomorphic, det(d_t F_j) never vanishes, and F_j -> F locally uniformly. Assume det(d_t F)(x,0) != 0 for every x in U. If F_j(U x C^n) avoids K_j, then F(U x C^n) avoids closure(Omega).
Proof: for fixed x, derivatives converge locally uniformly. Hurwitz applied to the nowhere-zero holomorphic functions det(d_t F_j(x,t)) says their limit is either nowhere zero or identically zero; the normalization at 0 excludes the latter. Hence F_x is a local biholomorphism, in particular open. For any fixed k and j>=k, F_j avoids K_k, so its limit avoids int(K_k). Thus F has image in C^n\Omega. Since each fiber image is open, it actually lies in int(C^n\Omega)=C^n\closure(Omega).
This lemma isolates a useful way to handle boundary contacts in decreasing exterior approximations. IT DOES NOT SUPPLY THE REQUIRED LOCALLY UNIFORM CONVERGENCE OR NORMALIZED FAMILY, which remain substantial missing inputs.
