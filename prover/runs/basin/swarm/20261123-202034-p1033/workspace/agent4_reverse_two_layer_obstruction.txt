TWO-LAYER OBSTRUCTION TO ECONOMICAL TARGETS IN THE REVERSE HALL GADGET
Let the reverse gadget have n colors x, and Q_F blocks. Suppose disjoint R,S each meet EVERY Q_F. For every color x, its A-type petals include all minimal transversals of {Q_F:x in F}; choose one P_x subset R, Pprime_x subset S. These exist by greedily minimizing R,S. If the incident block family is nonempty, both are nonempty. For every x != y, P_x and Pprime_y are disjoint. Any original-intersection target assignment must have y in T(P_x) or x in T(Pprime_y). Sum this over all n(n-1) ordered cross-layer pairs. Each target occurrence on a selected petal satisfies exactly one such pair. Thus the selected 2n petals together require at least n(n-1) target occurrences, so some needs >=(n-1)/2 targets.
In the owner-factored reverse gadget every Q_F contains Q_i of its owner. If every core size c_i>=3, each Q_i has >=2 points; choose disjoint a_i,b_i in Q_i and set R={a_i}, S={b_i}. This supplies the hypothesis. Thus max target budget is Omega(n), not O(t) when n~t^2. The argument applies to clones as well, with n replaced by the number of distinct outer colors.
Actual Python verification uses the regular tournament inner t=5, k=5, five cores of size3, 45 edges, factor ground40. It chooses all 30 A-type minimal transversals inside disjoint global R,S, checks all 210 ordered cross-color disjointness requirements, and verifies their aggregate needs budget>=7. A regular 15-color tournament uses exactly7 target labels per selected petal and satisfies all cross-layer requirements, confirming tightness of the counting obstruction for these chosen layers.
This refutes only the unmodified reverse-gadget target strategy, not a different actual-petal augmentation. It gives no new lower bound for b(t).
