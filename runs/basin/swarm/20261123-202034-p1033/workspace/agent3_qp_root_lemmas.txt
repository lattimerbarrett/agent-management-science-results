Quadratic optimization / root facts (agent_3, coordinated agent_1).
Let petal candidates be vertices, with Kneser adjacency B_uv=1 iff u!=v and their petals are disjoint; diagonal B=0. Let A=J-B, so A_uv=1 iff petals intersect for distinct vertices, and A_uu=1 by convention. Maximize Q(mu)=sum_{u<v} B_uv mu_u mu_v subject to nonnegative weights with each color total1. Any original-core orientation bounds cross-color contribution by dt, and same-color contribution is at most1/2 per color, so Q<=dt+t/2.
One can choose a maximizer with pairwise DISJOINT petal supports inside each color: among maximizers minimize support; if two supported same-color petals intersect then B_uv=0 and Q is linear when shifting weight between u,v, so an endpoint is also optimal, contradiction. Thus A diagonal color blocks are identities on positive support.
For any direction z of totalweight0 in each color, supported on strictly positive coordinates, local maximality implies z^T B z<=0; since z^T J z=0, z^T A z>=0. Thus A is PSD on color-zero-sum subspace.
For root vectors e_u-e_v from same supported color, norm^2 under A equals2, and all pair innerproducts are integers in[-2,2]. Modulo nullspace this gives a positive-definite integral root lattice generated by norm2 roots; reflection closure is finite simply-laced ADE. This statement needs the usual finite root-lattice classification only if used further.
Dummy extension: add one dummy per color, all representing same new point p0, disjoint from all actual petals. If two colors have both dummy and actual positive support, roots r_u=e_u-e_dummy(i) satisfy norm^2=2, and cross-innerproduct=1+A_actual(u,v). If actual petals intersect, innerproduct2 forces equal roots; hence intersection among actual supported petals of dummy-mixed colors is an equivalence relation, and distinct classes consist of disjoint petals. This is rigorous but currently does not control colors with zero dummy weight.
