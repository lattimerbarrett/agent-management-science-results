# Verified upper-bound support lemmas

Let `rank` mean common facet cardinality. These lemmas do not prove the requested universal completion bound.

## 1. Links
Every link of a pure k-decomposable complex is k-decomposable.
Proof: induction on a decomposition tree. For shedding face sigma and target face tau, if sigma is contained in tau, take a link in link_sigma. If sigma union tau is not a face, take a link in deletion_sigma. Otherwise sigma minus tau sheds link_tau: its deletion is link_tau(deletion_sigma), pure of the same rank as link_tau, and its link is link_(sigma union tau). Both arise lower in the decomposition tree.

## 2. Pure skeletons
For 1 <= q <= rank(Delta), the subcomplex generated by all q-faces is k-decomposable. Induct using shedding sigma. If |sigma| > q, the skeleton equals the skeleton of deletion_sigma (every q-face inside sigma is supported by a facet not containing sigma, by purity of deletion). If |sigma| <= q, sigma sheds the skeleton, its deletion is the q-skeleton of deletion_sigma, and its link is the (q-|sigma|)-skeleton of link_sigma. For rank zero use the simplex {empty} convention.

## 3. Decomposable prefix order
Every k-decomposable pure complex has an ordering of its facets whose nonempty prefixes generate k-decomposable complexes. For shedding sigma, first take the recursive order on deletion_sigma, then append sigma union L for L in the recursive link order. At every appended prefix sigma sheds: every proper subface not containing sigma is already in deletion_sigma, and the new link is a k-decomposable prefix. Base case: simplex.

## 4. Facetwise truncated joins
For a new vertex a, Delta can be enlarged to the pure rank-r skeleton of Delta * 2^{a} by adding one facet at a time through k-decomposable complexes. Take a prefix order of the rank-(r-1) skeleton of Delta, and add a union R in that order. At every nonempty prefix, a is shedding, deletion_a is Delta, and link_a is the corresponding prefix. Repeat to obtain any number of new vertices.

## 5. Cloning
For any existing vertex x and new a, add a union R for the facets R of link_x Delta in a k-decomposable prefix order. Each prefix has a shedding. At the end x is also shedding, since deletion_x is Delta with x relabeled a, and link_x is unchanged.

## Exact finite checks
`agent2_decomp.py` implements literal recursive k-decomposability, not just homological necessary conditions. `check()` exhausts all pure facet families supported on <=5 labeled vertices, and k=0,1,2. It found 5,889 decomposable instances and checked all five assertions (all links, all positive-rank skeletons, all decomposable-prefix stages, each truncated-cone stage, clone and its deletion). It terminates in roughly 1 second here. The implementation includes memoized witnesses, so proofs can be extracted by repeating recursion.
