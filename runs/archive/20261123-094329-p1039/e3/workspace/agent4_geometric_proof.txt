For n>=3, write z=(zprime,w) in C^(n-1) x C and set rho=||zprime||^2+(|w|^2-1)^2-4. Let Omega={rho<0}, K={rho<=0}. For t=|w|^2, fiber radius squared is 4-(t-1)^2=(3-t)(1+t). Thus base is the disk |w|<sqrt(3); fibers are nonempty balls. Omega is bounded and connected: first contract zprime linearly to zero inside each fiber, then contract w radially to zero in the base disk. The gradient vanishes only if zprime=0 and either w=0 or |w|^2=1; these give rho=-3 and -4 respectively, so d rho never vanishes on rho=0. Every boundary point is in closure Omega by the regular-value theorem, so K=closure Omega and K is in the required class. The complex Hessian is diag(I_(n-1),4|w|^2-2). At q=(sqrt(3),0,...,0), the w direction is complex tangent and has Levi value -2; boundary is not pseudoconvex. At any point with zprime nonzero, the space {(vprime,0):sum conj(zprime_j)*vprime_j=0} has dimension n-2 and Levi form ||vprime||^2. If zprime=0 on boundary then |w|^2=3, so all zprime directions are tangent with Levi value ||vprime||^2. Consequently for n>=3 there is a positive Levi direction everywhere. THIS DOES NOT PROVE THAT THE EXTERIOR IS OKA: a genuine Oka theorem is still required. No such theorem has been established by this script or this agent.
